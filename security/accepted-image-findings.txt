# Image findings knowingly carried, with the reason each one is carried.
#
# Format:  <image>  <CVE>  # reason (date)
#
# This is the counterpart to `.gitleaksignore` and follows the same rule: it is not a way
# to hide a finding, it is a record that someone looked at it, decided, and left a date.
# `scripts/scan-images.py` fails on any finding that is not listed here, so an image cannot
# quietly accumulate new ones - a CVE that appears tomorrow is not covered by yesterday's
# entry.
#
# What belongs here: findings on an image that is already on its newest upstream tag. Those
# come from the base image the upstream builds on and cannot be fixed from this repository;
# they clear when the upstream rebuilds. What does NOT belong here: a finding that a newer
# tag would clear. The scanner treats that as a failure and it should be fixed by bumping
# the pin, not by adding a line below.
#
# Review: entries older than 90 days are reported by the scanner. Re-check them rather than
# refreshing the date - the point is to notice when an upstream has stopped rebuilding.
#
# Note that the finding set depends on the scanner version, which is why TRIVY_VERSION in
# scripts/scan-images.py is pinned and checked against the CI workflow. This list was
# produced with trivy 0.74.0 on 2026-08-20 (issue #67), refreshed 2026-09-16 (issue #108)
# after the weekly image-scan run found four pins behind a fixable patch and every
# newest-tag image carrying findings this file's 2026-08-20 CVE list no longer covered.
# Refreshed again 2026-10-08 (issue #115): the same four-pins-behind situation, bumped;
# entries for the replaced tags removed, and the remaining findings generated in a
# CI-identical container (trivy binary, fresh vulnerability DB), not from a local cache.
# 2026-10-09 (#124): alloy, BridgeLink and alertmanager moved to their newer series;
# their old-tag entries removed. Two Go standard library CVEs published 2026-10-08 hit
# eight images at once and are recorded per image until upstreams rebuild.
# 2026-10-27 (#131): grafana, loki, prometheus and python bumped to their newest patches;
# entries for the replaced tags removed. CVE-2026-111943 (Go stdlib, 2026-10-21) and a few
# base-image CVEs published since hit the newest-tag images and are recorded per image.
# 2026-10-12 (#128): a third CVE of the same batch (CVE-2026-78669, published later on
# 2026-10-08) reached the vulnerability DB after that and hit the same eight images.
